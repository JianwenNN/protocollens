-----------------------------------
FIELD EXTRACTION GUIDANCE
-----------------------------------

=== trial_metadata ===

Extract the official trial identification information.

- title: The official protocol title or study title
  * Usually found on title page or in "Protocol Title" section
  * Include the full title, not abbreviated
  * Example: "A Phase 2, Randomized, Double-Blind Study of Drug X in Patients with Advanced Cancer"

- phase: The clinical trial phase
  * Look for: "Phase 1", "Phase 2", "Phase 3", "Phase 4", "Phase 1/2", "Phase 2/3"
  * May appear as "Phase I", "Phase II", etc.
  * If not specified, leave empty

- status: Current trial status
  * Common values: "recruiting", "active", "completed", "terminated", "not yet recruiting"
  * Often found in ClinicalTrials.gov ID section or header
  * If not specified, leave empty

=== study_design ===

Extract the fundamental study design characteristics.

- type: Basic study design type
  * Common values: "randomized controlled trial", "single-arm", "crossover", "observational", "dose-escalation"
  * Look in "Study Design" or "Design Overview" sections
  * Be specific: "open-label, single-arm, phase 2 study" is better than just "single-arm"

- randomization: Randomization approach
  * Values: "randomized", "non-randomized", "not applicable"
  * Look for phrases like "patients will be randomized", "randomization ratio"
  * If ratio specified, include it: "randomized (1:1)" or "randomized (2:1)"

- blinding: Who is blinded
  * Values: "open-label", "single-blind", "double-blind", "triple-blind"
  * "Open-label" means no blinding
  * Specify who is blinded if stated: "double-blind (patient and investigator)"

- control: Type of control arm
  * Values: "placebo", "active comparator", "standard of care", "none", "historical control"
  * Specify the comparator if named: "active comparator (chemotherapy)"
  * For single-arm studies: "none"

=== population ===

Extract the target patient population characteristics.

- indication: Primary disease or condition under study
  * Use exact medical terminology from protocol
  * Include stage/type if specified in indication
  * Examples: "metastatic breast cancer", "relapsed/refractory acute myeloid leukemia", "type 2 diabetes mellitus"

- disease_stage: Specific disease stage or classification
  * Look for TNM staging, FIGO staging, disease classification
  * Examples: "Stage III-IV", "locally advanced or metastatic", "relapsed/refractory"
  * Only include if explicitly stated; don't infer from indication

- biomarkers: Required or relevant biomarkers
  * Extract as a list of strings
  * Include marker name and status if specified
  * Examples: ["HER2-positive", "EGFR mutation", "PD-L1 ≥50%", "KRAS wild-type"]
  * Include testing method if specified: "ALK-positive by IHC or FISH"

- age_range: Eligible age range
  * Extract exact age criteria
  * Examples: "18 years and older", "18-75 years", "≥65 years"
  * If only minimum: "≥18 years"; if only maximum: "≤75 years"

=== eligibility.inclusion / exclusion ===

Each criterion MUST be an ATOMIC condition.

⚠️ CRITICAL: Extract EVERY criterion. Count the numbered items in the protocol and ensure your output count matches.

Each criterion object MUST follow this structure:

{
  "id": "INC_01" or "EXC_01",
  "text": "<verbatim criterion text>",
  "category": "<age | diagnosis | disease_stage | biomarker | performance_status | lab_value | prior_therapy | comorbidity | reproductive | consent | other>",
  "operator": "<>= | <= | = | in_range | required | prohibited | none>",
  "value": "<value if applicable, else empty string>",
  "confidence": <number between 0.0 and 1.0>,
  "source_evidence": [
    {
      "section": "<section name>",
      "quote": "<exact quote from protocol, max 200 chars>",
      "page": <page number or null>
    }
  ]
}

Guidelines:
- Extract EVERY numbered item, including administrative criteria like "signed informed consent"
- Multi-part criteria (1a, 1b, 1c): Create SEPARATE criteria for each part
- Compound "AND" conditions: Split if clearly distinct requirements
- Use verbatim text from protocol
- Sequential IDs: INC_01, INC_02, etc.

=== interventions ===

⭐ ENHANCED: Extract complete intervention/treatment information ⭐

CRITICAL: Extract ALL treatment arms with complete details.

Look for sections titled: "Treatment", "Study Treatment", "Investigational Product", "Treatment Arms", "Study Arms"

Each intervention object represents ONE treatment arm and should include:

- arm_name: Name of the treatment arm
  * Examples: "Arm A: Experimental", "Cohort 1", "Treatment Group", "Dose Level 1"
  * If single-arm: "Single Arm" or the treatment name
  * For dose-escalation: include dose level info

- treatment: Drug/intervention name(s)
  * Include generic and brand names if both given
  * For combinations: list all components
  * Examples: "Pembrolizumab (Keytruda)", "Carboplatin + Paclitaxel", "Drug X 100mg + Drug Y 50mg"
  * Include formulation if specified: "Drug X (oral tablet)"

- dose: Dosing amount
  * Include complete dose information with units
  * Examples: "200 mg", "5 mg/kg", "AUC 5", "100 mg/m²"
  * For dose ranges: "100-200 mg" or "starting dose 100 mg, may escalate to 200 mg"
  * For multiple components: specify each: "Drug A: 100mg, Drug B: 50mg"

- route: Route of administration
  * Common values: "intravenous (IV)", "oral (PO)", "subcutaneous (SC)", "intramuscular (IM)", "intraperitoneal"
  * Include infusion details if specified: "IV infusion over 30 minutes"
  * For multiple routes: list each

- schedule: Dosing schedule and frequency
  * Be complete and specific
  * Examples: 
    - "once daily for 21 days, repeated every 28 days"
    - "Days 1 and 8 of each 21-day cycle"
    - "continuous dosing"
    - "weekly for 3 weeks, followed by 1 week rest"
  * Include cycle length: "28-day cycles" or "21-day cycles"
  * Include duration if specified: "for 6 cycles" or "until progression"

⚠️ SPECIAL CASES:
- Dose-escalation studies: Create separate intervention objects for each dose level/cohort
- Combination therapies: Include all drugs with their individual doses in one intervention
- Placebo arms: Still create intervention object with treatment="placebo"
- Multiple phases: Specify if induction/maintenance/consolidation phases have different dosing
